# go-pcore documentation

MkDocs Material sources for the **go-pcore** documentation, versioned with
[mike] and served at <https://go-pcore.github.io/docs/>.

## Local preview

```sh
pip install -r requirements.txt
mkdocs serve
```

The `docs` workflow publishes versioned docs to the `gh-pages` branch on every
push to `main`.

[mike]: https://github.com/jimporter/mike
